## Diferencia entre `return` y `yield`

### `return`
- Devuelve un resultado final y termina la función.
- Se usa cuando quieres obtener la respuesta completa de una sola vez.

### `yield`
- Devuelve un valor por vez, pero la función no termina del todo.
- Se usa para generar resultados poco a poco.
